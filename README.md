# Electra Engineering Group Website

A premium responsive React/Vite website for a female-led electrical engineering and energy company based in Ghana.

## Run locally

1. Install Node.js.
2. Open a terminal in this folder.
3. Run:
   npm install
   npm run dev

## Before launch

Replace:
- `[Founder Name]` and team placeholders
- phone/WhatsApp number
- email address
- office address
- project examples
- placeholder visuals with real company/project photos
- LinkedIn profile links
- quote-form submission with Formspree, EmailJS, Netlify Forms, Firebase, or a company backend

## Build for deployment

npm run build

The production files will be in `dist/`.

## Suggested domain

Use a professional domain such as:
electraengineering.com
electraengineeringgh.com
or the company's actual registered brand domain.
